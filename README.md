# Karaoke Remote (가칭)

YouTube의 [TJ노래방 채널](https://www.youtube.com/@TJ%EB%85%B8%EB%9E%98%EB%B0%A9TJKaraoke/videos) 영상을 노래방처럼 즐기기 위한 Chrome 확장 프로그램입니다. 노래방 리모컨을 닮은 조작 화면에서 곡을 찾고 예약하며, 재생 중 키와 템포를 조절하는 것을 목표로 합니다.

> **상태: 로컬 프로토타입 개발 중.** Chrome 확장 프로그램 코드는 [`extension/`](extension/)에 있습니다. 아래 P0 표는 제품 목표이며, 실제 구현 상태는 다음 절에 구분했습니다.

## 현재 구현 상태

| 기능 | 상태 |
| --- | --- |
| 리모컨 UI | 제공된 `karaoke_design.zip` 시안을 바탕으로 Chrome 사이드 패널 구현 |
| 세션 예약·예약 삭제·선택 곡 바로 시작·다음 곡·현재 곡 취소 | 구현, 자동 테스트 통과. 실제 YouTube 화면에서의 최종 확인 필요 |
| 채널 검색 | TJ노래방 채널 검색 결과를 확장 프로그램 안에서 가져와 표시. 실제 Chrome에서 검색 결과 30개와 재생 탭 유지 확인 |
| 템포 ±0.1배·원상복구 | YouTube 영상에 적용하고 실제 속도를 읽도록 구현. 영상별 동작 확인 필요 |
| 멜론 TOP100 | 공식 차트 페이지를 읽어 목록으로 표시하도록 구현. 실제 확장 프로그램에서 확인 필요 |
| 멜론 TOP100 곡 예약 | 곡을 누르면 같은 멜론 화면 안에 TJ 영상 후보를 표시. 후보가 한 개여도 원하는 영상을 눌러 예약. API 키가 없어도 채널 검색 사용 |
| 키 ±5반음 | 영상 탭에서 확장 프로그램 아이콘을 누를 때 탭 소리를 연결하고, 버튼으로 음정만 조절. 버튼 한 번에 1반음, 범위는 −5~+5. 실제 Chrome에서 탭 캡처와 +5 표시 확인, 음질·싱크 확인 필요 |

### 로컬 설치와 사용

1. Chrome에서 `chrome://extensions`를 열고 **개발자 모드**를 켭니다.
2. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 폴더의 [`extension/`](extension/)을 선택합니다.
3. YouTube의 TJ노래방 **영상 탭에서** 확장 프로그램 아이콘을 눌러 사이드 패널을 엽니다. 이때 키 조절용 탭 소리가 연결됩니다. 기존 설치를 수정한 경우 `chrome://extensions`에서 확장 프로그램을 **새로고침**하고, 이미 열려 있던 YouTube 영상 탭도 **새로고침**한 뒤 아이콘을 다시 눌러 주세요.
4. 곡을 검색·예약하거나 멜론 TOP100을 펼칩니다. 멜론 순위의 곡을 누르면 같은 화면에 TJ 영상 후보가 나타납니다. 원하는 후보의 `+예약`을 누르면 예약이 완료됩니다. YouTube Data API 키는 선택 사항이며, 저장하면 Chrome의 로컬 저장소에 보관됩니다.

키 변경 중에는 **탭 전체 소리**가 처리되며, 음질이나 소리와 영상 사이에 약간의 지연이 생길 수 있습니다. 원키나 다음 곡에서는 소리를 그대로 통과시켜, 같은 탭에서 다시 키를 조절할 수 있게 합니다. Chrome에서의 실제 음질·싱크는 확인이 필요합니다.

개발자용 확인 명령: 프로젝트 폴더에서 `node --test tests/*.test.cjs`를 실행합니다. 제공된 디자인에 쓰인 Jua·Share Tech Mono 글꼴은 확장 프로그램에 함께 넣었고, 각 글꼴의 라이선스는 [`extension/fonts/`](extension/fonts/)에 있습니다. 음정 처리는 [SoundTouchJS AudioWorklet](https://github.com/cutterbl/SoundTouchJS/tree/master/packages/audio-worklet) 2.1.1을 포함하며 MPL-2.0 라이선스는 [`extension/vendor/soundtouch/LICENSE`](extension/vendor/soundtouch/LICENSE)에 있습니다.

## 사용 흐름

1. YouTube에서 TJ노래방 영상을 열고 확장 프로그램의 리모컨을 엽니다.
2. 채널 내 검색 또는 멜론 TOP100에서 부를 곡을 찾아 예약합니다.
3. 예약 목록을 보면서 현재 곡의 키와 템포를 조절합니다.
4. 예약을 취소하거나 현재 곡을 건너뛰어 다음 곡을 재생합니다.

## P0 기능

| 기능 | 기대 동작 |
| --- | --- |
| 템포 − / + | 한 번 누를 때마다 **원곡 속도 1.0배를 기준으로 0.1배씩** 낮추거나 높입니다. 예: `1.0 → 1.1 → 1.2`. |
| 키 − / + | 한 번 누를 때마다 **반음씩** 낮추거나 높입니다. 조절 범위는 원곡 기준 **위아래로 반음 5단계(±5반음)**입니다. |
| 원상복구 | 키를 원곡으로, 템포를 `1.0배`로 함께 되돌립니다. |
| 예약 / 예약 목록 | 현재 선택한 TJ노래방 영상을 **현재 노래방 세션의 예약 목록**에 추가합니다. 목록의 `▶ 시작`으로 원하는 곡을 바로 재생하거나 `다음곡`으로 순서대로 재생합니다. 사용자 YouTube 계정의 재생목록에는 저장하지 않습니다. |
| 채널 내 검색 | 검색 버튼으로 **TJ노래방 채널 YouTube 자체 검색 결과**를 확장 프로그램 안에 표시하고, 찾은 영상을 예약합니다. 현재 재생 중인 탭은 이동하지 않습니다. |
| 멜론 TOP100 | 리모컨에서 [멜론 TOP100](https://www.melon.com/chart/)을 펼쳐 순위를 봅니다. 곡을 누르면 같은 멜론 화면 안에서 TJ노래방 영상 후보를 보여주며, 후보가 하나여도 직접 예약을 완료합니다. 찾을 수 없으면 같은 화면에 이유를 표시합니다. |
| 예약 취소 | 예약 목록에서 선택한 곡을 제거합니다. |
| 현재 곡 취소 | 리모컨의 `취소` 버튼으로 재생 중인 곡을 중단합니다. |
| 스킵 / 다음 곡 | 현재 곡을 건너뛰고 다음 예약곡을 재생합니다. |
| 상태 디스플레이 | 현재 곡, 키, 템포, 다음 예약곡, 예약곡 수와 조작 결과를 작은 화면에 표시합니다. |

### 조작 규칙

- 키와 템포는 **원곡 기준값**을 표시합니다. 예: `KEY +2`는 원곡보다 반음 2단계 높고, `TEMPO 1.1×`는 원곡보다 0.1배 빠릅니다.
- 키 조절은 원곡에서 반음 5단계 위아래를 넘지 않습니다.
- 예약 목록은 현재 노래방 세션에만 유지하며 YouTube 계정과 동기화하지 않습니다.
- `원상복구`는 두 값을 한 번에 초기화합니다.
- `예약 취소`는 선택한 예약곡에 적용하고, `스킵`은 재생 중인 곡에 적용합니다.
- 예약곡이 없을 때 스킵하면 새 영상을 임의로 재생하지 않습니다.
- 다음 곡으로 넘어갈 때 키와 템포를 원곡 기준으로 초기화하는 것을 기본 동작으로 합니다.

## 디자인 방향

[노래방 리모컨 레퍼런스](https://www.ebay.com/itm/358527733651)의 **물리적인 버튼 배치와 작은 상태창**에서 영감을 받습니다. 실제 조작에 필요한 버튼만 남기고, 키보드·숫자 패드·사용하지 않는 기능 버튼은 넣지 않습니다.

- 상단: 현재 상태를 읽을 수 있는 작은 디스플레이
- 중앙: 손으로 누르기 쉬운 `키 −/+`, `템포 −/+`, `원상복구` 버튼
- 하단: `검색`, `멜론 TOP100`, `예약`, `예약 목록`, `예약 취소`, `스킵` 버튼
- 버튼은 라벨을 읽기 쉽고 상태 변화를 알아볼 수 있게 디자인합니다.

제공된 `karaoke_design.zip`의 화면 색상·형태·배치를 확장 프로그램에 반영했습니다. 레퍼런스 상품 페이지의 상세 이미지는 이 문서 작성 시 직접 확인하지 못했습니다.

## 구현 전 검증할 사항

1. **키 변경:** Chrome의 탭 캡처와 AudioWorklet을 연결했습니다. 실제 TJ 영상에서 ±5반음의 음정, 음질, 영상과 소리의 싱크, 다른 재생속도와의 조합을 확인해야 합니다. 배포 전에는 YouTube 관련 이용 조건도 별도로 검토합니다. [Chrome 탭 캡처](https://developer.chrome.com/docs/extensions/reference/api/tabCapture), [SoundTouchJS](https://github.com/cutterbl/SoundTouchJS/tree/master/packages/audio-worklet), [YouTube API 서비스 정책](https://developers.google.com/youtube/terms/developer-policies)
2. **0.1배속 템포:** YouTube 플레이어는 영상별로 지원하는 재생속도가 다르며, 지원하지 않는 속도 요청은 정확히 적용되지 않을 수 있습니다. `1.1×` 같은 값이 실제 YouTube 페이지에서 적용되는지 검증하고, 디스플레이에는 요청값이 아니라 **실제 적용값**을 보여줍니다. [YouTube IFrame Player API](https://developers.google.com/youtube/iframe_api_reference)
3. **세션 예약 목록:** YouTube 영상으로 구성된 예약 목록의 순서·취소·스킵이 현재 노래방 세션에서 일관되게 동작하는지 확인합니다.
4. **멜론 TOP100 곡 연결:** 순위 데이터를 안정적으로 가져오는 방법과 멜론 곡을 TJ노래방 영상에 정확히 대응시키는 방법을 확인합니다. 동명곡·여러 버전은 모달에서 사용자가 고르고, 미등록곡은 예약하지 않아야 합니다. [멜론 TOP100](https://www.melon.com/chart/)

## 개발 순서와 완료 기준

1. **기능 검증** → 실제 YouTube 영상에서 속도 단계와 반음 5단계까지의 키 변경 가능 여부, 세션 예약 목록의 재생 방식, 멜론 차트 접근 방식을 확인합니다.
2. **리모컨 UI와 상태 표시** → 디자인 시안을 반영하고 버튼 조작 결과가 디스플레이에 즉시 보이는지 확인합니다.
3. **검색과 예약** → 채널 검색으로 찾은 영상과 멜론 차트에서 선택한 영상이 올바른 순서로 예약되는지 확인합니다.
4. **재생 제어** → 키·템포·초기화·취소·스킵을 실제 영상에서 시험하고, 다음 곡 시작 시 상태가 초기화되는지 확인합니다.

## 범위

첫 버전은 Chrome에서 TJ노래방 채널 영상을 조작하는 기능에 집중합니다. 마이크 입력, 점수 계산, 녹음, 숫자 검색 패드 등은 현재 요구사항에 포함되지 않습니다.
